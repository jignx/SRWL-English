Super Robot Wars L English v1.4

v1.4 fixes several bugs from the original game and a few menu problems. The script is the
same as v1.3.2. Earlier BGM add-ons don't fit v1.4; use the v1.4 add-ons.

Two patches give the same patched ROM:
- SRWL_English_v1.4.html: offline browser patcher, accepts both clean dumps below.
- SRWL_English_v1.4.bps: standard BPS patch for the canonical-header dump.
Both verified by patching fresh copies of the clean dumps; identical output hash below.

Optional vocal BGM add-ons apply to the patched ROM (use one). The HTML patcher
can apply one too, from the Japanese ROM or from an already-patched v1.4 ROM:
- SRWL_English_v1.4_StereoBGM_addon.bps: stereo vocal BGM.
- SRWL_English_v1.4_MonoBGM_addon.bps: smaller mono fallback.
